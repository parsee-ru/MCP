# ПАРСИ · MCP

Подключение ИИ-ассистента к **ПАРСИ** — приложению для сбора и мониторинга товаров на Ozon и Wildberries.

После подключения ассистент (Claude, Kimi, Cursor и любой другой с поддержкой MCP) умеет искать товары, запускать сбор, читать собранные данные, вести группы мониторинга и сравнения, считать СПП и ставить проверки по расписанию — по-человечески, без кнопок и таблиц.

---

## Обязательное условие

**Нужно установленное и запущенное приложение ПАРСИ** — [parsee.ru](https://parsee.ru)

Это не прихоть, а устройство продукта: сервер MCP входит в состав приложения и слушает только `127.0.0.1`. Сбор идёт **с компьютера продавца и под его сессиями** Ozon и Wildberries — так устроена защита от блокировок маркетплейсов. Отдельно, без приложения, подключаться просто не к чему: порт закрыт, ключа не существует.

Проверить, что всё на месте:

```bash
curl http://127.0.0.1:7317/health
```

Ответ `{"ok":true,"name":"parsee-mcp"}` означает, что приложение запущено и готово. Если ответа нет — откройте ПАРСИ.

---

## Подключение

Ключ доступа выдаёт само приложение: **Подключение ИИ** → строка вида `psk_…`. Ключ локальный, никуда не отправляется, отзывается одной кнопкой.

### Claude Code

```bash
claude mcp add parsee --transport http http://127.0.0.1:7317/mcp --header "Authorization: Bearer ВАШ_КЛЮЧ"
```

### Claude Desktop, Kimi, Cursor и другие

```json
{
  "mcpServers": {
    "parsee": {
      "url": "http://127.0.0.1:7317/mcp",
      "headers": { "Authorization": "Bearer ВАШ_КЛЮЧ" }
    }
  }
}
```

При подключении сервер сам отдаёт ассистенту инструкцию: порядок работы, чем отличаются группы, чего делать нельзя. Отдельно её можно перечитать инструментом `parsee_help`.

## Что умеет ассистент

28 инструментов, 15 из них только читают данные. Полный машиночитаемый список — [`tools.json`](tools.json).

### Найти и собрать
| Инструмент | Что делает |
|---|---|
| `parsee_browser_search` | Поиск словами. Отдаёт **только ссылки** — ни цен, ни рейтинга |
| `parsee_parse_category` | Категория, выдача, бренд или продавец целиком — одной ссылкой |
| `parsee_parse_urls` | Сбор карточек по списку ссылок или артикулов |
| `parsee_wait` | Дождаться конца сбора и только потом ответить |
| `parsee_get_results` | Прочитать собранное: цена, цена с картой, рейтинг, отзывы, наличие |
| `parsee_export` | Выгрузить в Excel, CSV, JSON или ZIP |

### Группы
| Инструмент | Что делает |
|---|---|
| `parsee_list_groups` | Все группы: мониторинг, сравнение, СПП |
| `parsee_create_group` | Создать группу и сразу наполнить |
| `parsee_add_to_group` / `parsee_remove_from_group` | Дополнить или почистить |
| `parsee_rename_group` / `parsee_delete_group` | Переименовать, удалить (только с подтверждением) |
| `parsee_run_check` | Проверить группу сейчас |

### Аналитика
| Инструмент | Что делает |
|---|---|
| `parsee_get_prices` | Цены по группе: витрина и цена с картой |
| `parsee_monitor_changes` | Что изменилось с прошлой проверки: цена, наличие, схема, рейтинг |
| `parsee_compare_diff` | Моя карточка против конкурента — кто дешевле |
| `parsee_spp_changes` | Где сдвинулась скидка постоянного покупателя |
| `parsee_price_history` | Как менялась цена товара |

### Настройка
| Инструмент | Что делает |
|---|---|
| `parsee_status` | Что происходит сейчас, сколько собрано |
| `parsee_get_options` / `parsee_set_options` | Фото, отзывы, характеристики, режим скорости |
| `parsee_get_region` / `parsee_set_region` | Город, из которого смотрятся цены — они разные по стране |
| `parsee_get_schedule` / `parsee_set_schedule` | Запуск по дням недели или каждые N часов |
| `parsee_wb_cabinet` | Цены, переданные площадке — основа расчёта СПП |
| `parsee_stop` | Остановить сбор |

## Как ассистенту работать правильно

1. `parsee_status` — не идёт ли уже сбор.
2. `parsee_set_options` — выключить фото и отзывы, если нужна только цена: сбор идёт в разы быстрее.
3. `parsee_parse_category` — взять рынок целиком. Либо `parsee_browser_search`, если нужен поиск словами.
4. `parsee_wait` — дождаться конца, а не опрашивать статус в цикле.
5. `parsee_get_results` — прочитать данные и только теперь делать выводы.

Главное правило: **выдача поиска — это не данные**. В ней нет ни точных цен, ни рейтинга, ни наличия. Выводы делаются по собранным карточкам.

## Безопасность

- Сервер слушает **только** `127.0.0.1` — снаружи недоступен.
- Ключ обязателен на каждом запросе и сравнивается за постоянное время.
- Встроенный браузер ходит **только** на `ozon.ru` и `wildberries.ru` — белый список.
- Кабинет продавца ассистенту недоступен: переданные цены приложение читает само, по ключу, который вводит владелец.
- Удаление групп — только после явного подтверждения пользователя.
- Каждое действие видно в журнале приложения, в реальном времени.

## Облачный сервер: справка + удалённый доступ

В репозитории есть `server.py` — один сервер, два режима на одном адресе (`https://parsee-mcp.fastmcp.app/mcp`):

- **Без ключа** — справка: `parsee_cloud_about`, `parsee_cloud_setup`, `parsee_cloud_tools`, `parsee_cloud_manual`. Данных продавца здесь нет, сервер ничего не собирает — только рассказывает, что такое ПАРСИ и как подключиться. Приставка `parsee_cloud_` не даёт модели спутать эти инструменты с настоящими.
- **С Bearer-ключом удалённого доступа** — работают настоящие 28 инструментов (`parsee_*`, без `cloud_`). Ключ выдаёт приложение (окно «Подключить ИИ» → «Удалённый доступ»). Каждый вызов пересылается на `relay.parsee.ru`, тот держит связь с приложением на компьютере продавца и выполняет команду там же — теми же функциями, что и обычный локальный сбор. Без ключа эти инструменты отвечают понятной ошибкой, а не выдумывают данные.

Так ассистенту не нужно выбирать, какой из двух адресов добавлять — сервер один, дальше решает наличие ключа.
